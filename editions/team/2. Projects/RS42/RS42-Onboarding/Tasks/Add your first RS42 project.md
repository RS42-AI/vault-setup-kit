# Add your first RS42 project

> **Parent**: [[RS42-Onboarding]]

Create a project hub at `2. Projects/RS42/{Your Project}/{Your Project}.md` using the Project Hub Template (`system-settings/Templates/`). Set `area: rs42` and a `project:` slug. Then add a task under its `Tasks/` folder. The area dashboard ([[RS42]]) will pick it up automatically.
