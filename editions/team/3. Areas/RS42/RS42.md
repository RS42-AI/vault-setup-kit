> [!note] Area Purpose
> Your RS42 work — projects, work logs, research, and the references the team shares.

This is a dashboard. It auto-populates from frontmatter on every other note. As you create notes with `area: rs42`, they appear in the sections below.

New here? Start with [[RS42-Onboarding]].

---

## Active Projects

```base
filters:
  and:
    - type == "project"
    - area == "rs42"
    - status == "active"
views:
  - type: table
    name: Active Projects
    order:
      - file.name
      - status
      - date
    sort:
      - property: date
        direction: DESC
```
